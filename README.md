# Data-cleaning-and-visualisation-project

This project was developed as part of the Thiranex Skill Development Program. It demonstrates a complete end-to-end data analysis workflow, including data cleaning, preprocessing, handling missing values, removing duplicates, detecting outliers, and visualizing insights using Python libraries such as Pandas, Matplotlib, and Seaborn.

The project focuses on transforming raw data into meaningful visual reports and business insights through Exploratory Data Analysis (EDA) and professional data visualization techniques.

---

## 🎯 Project Objective

- 📌 Clean and preprocess raw datasets
- 📌 Handle missing values and duplicates
- 📌 Detect outliers in the dataset
- 📌 Perform Exploratory Data Analysis (EDA)
- 📌 Create professional visualizations
- 📌 Extract meaningful insights from data
- 📌 Learn real-world data analysis workflow
